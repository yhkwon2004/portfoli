# 권용현 — Developer & Maker

ALCHE의 대형 타이포그래피, 곡면 격자, 유리 3D, 가로 작품 전개를 참고해 만든 개인 포트폴리오입니다. GitHub 저장소와 공개 Notion의 실제 프로젝트·수상·학력·경험·자격 자료를 반영했습니다. 원본과 세부 광학 효과 및 전환 타이밍은 다를 수 있습니다.

## 실행

Node.js가 설치된 환경에서 이 폴더를 열고 실행합니다.

```sh
npm start
```

[로컬 미리보기](http://localhost:4173/)에서 확인할 수 있습니다. 외부 패키지 설치는 필요하지 않습니다. 종료는 터미널에서 Ctrl+C입니다. HTML 더블클릭 대신 서버로 열어야 모듈과 3D 자산이 로드됩니다.

## 구현 내용

- 첫 화면: 개발자를 표현하는 3D 유리 `</>` 심볼, 곡면 격자, 자산 로딩 진행률. 대표작과 전체 목록은 AI(FACTLINE)→자작차→자율주행→IoT 링거폴대를 먼저 보여줍니다. 대표작 6개는 한 번의 휠·드래그에 한 장씩 이동하며 키보드·버튼도 지원합니다.
- 소개와 철학: 하나의 프로젝트 회상 배경이 Mission에서 Vision까지 이어지고, 카드 없이 문장과 단어별 마스크 등장에 집중합니다. Vision은 짧은 구간에서 자연스럽게 스크롤합니다. 연락처도 드래그에 반응합니다.
- Recognition: 도지사 대상·지방중기청장 최우수상·시장 대상의 실제 상장이 겹쳐 교차하며 선택한 기록이 앞으로 나옵니다. 수여기관·상격·연결 프로젝트를 표시하고 모션 감소 설정에서는 한 장만 정적으로 보여줍니다. HUSS AI·IoT 성과는 메인 기사와 전체 수상 목록에서도 탐색할 수 있습니다.
- 공식 기관 로고 9개는 멈춤 없이 두 줄로 흐릅니다. 연락처에는 Instagram·GitHub·Notion·Blog 아이콘과 이름을 표시합니다.
- `/works/`: 전체 프로젝트 39개, 분야·연도·검색 필터. 검색 조건은 주소에 저장됩니다.
- `/works/프로젝트-ID/`: 한 줄 아이디어, 참여 인원·팀, 본인 역할, 제작 과정·기술·원문, 관련 작품과 이전·다음 작품. 확인되지 않은 참여 정보는 미기재로 표시합니다.
- 이미지 확대: 썸네일 탐색, 여러 이미지 순환, 좌우 방향키, Escape 닫기, 닫은 뒤 원래 버튼으로 포커스 복귀. 전기차·자율주행 준비 사진은 작성자의 정정에 따라 재분류했습니다.
- 영상: 자료에 포함된 실제 YouTube 영상 4개를 클릭해 페이지 안에서 재생. 원문 영상 링크도 함께 제공.
- `/news/`: 실제 공식 기사 9건, 수상 기록 37개. HUSS AI·IoT 캡스톤·생활혁신 기사를 홈에 노출합니다. 직접 소개와 행사 관련 보도를 구분하며, 관련 프로젝트에서도 기사 원문으로 연결됩니다.
- `/about/`: 실제 소개·학력·경험·자격과 현장 사진 갤러리, GitHub·Notion·블로그·이메일 연결.
- `/activities/`: 2023 LLM 연구실, 2024 공유대학 복수전공, 2024–2025 드론 교육, 2025 창업동아리 연계 인턴십, 2025–2026 IoT 연구실의 활동 타임라인.
- `/motion/`: Developer Lab. 실제 프로젝트 4개의 문제·설계·검증 과정을 네이티브 아코디언으로 탐색합니다.
- 모바일 메뉴, 키보드 이동, 동작 줄이기 설정, WebGL 실패 시 정적 배경, 이미지 로딩 오류 시 재시도.
- 페이지별 주소, 새로고침, 브라우저 뒤로·앞으로 이동. 별도의 프레임워크나 라우팅 라이브러리 없이 동작.

## 참고 화면과 콘텐츠 대응

ALCHE의 데스크톱·모바일 화면에서 헤더, 작품 이미지 비율, 고정 장면, 작품 목록을 비교했습니다. 홈의 대형 배경 제목을 정리하고 아래 구성을 적용했습니다.

| 참고 구성 | 포트폴리오 대응 |
| --- | --- |
| 유리 오브젝트와 중앙 워드마크 | 개발 기호 `</>`, KWON 워드마크, 곡면 그리드 |
| 곡선으로 이동하는 16:9 작품 | 실제 대표 프로젝트 6개, 드래그·방향키·버튼 탐색 |
| Mission / Vision | 연속적인 프로젝트 회상 배경과 문장 |
| Service 이미지와 설명 | 실제 수상 이력과 프로젝트 연결 |
| 왼쪽 분류와 오른쪽 2열 Works | 분야·검색·연도 필터, 모바일 한 열 |

작품과 상장은 6px의 가벼운 드래그부터 한 장씩 이동하며 420ms로 전환합니다. 낮은 화면에서도 Recognition을 일반 흐름과 탭·드래그로 탐색해 내용이 잘리지 않게 합니다. 모션 감소 설정에서는 이동 효과를 줄입니다.

## 소스 안내

| 파일 | 내용 |
| --- | --- |
| `content.js` | 이름, 연락처, 소개, 뉴스, 대표 프로젝트 순서 |
| `data.js` | 전체 프로젝트와 수상·경험 기록 |
| `assets/portfolio/` | 본인 프로젝트 이미지 원본과 썸네일 |
| `pages.js` | 작품 목록·상세·소개·소식·모션 페이지 구성 |
| `app.js` | 라우팅, 필터, 로딩, 확대 보기, 영상, 메뉴, 사운드 |
| `page-transition.js` | 페이지 이동과 뒤로 가기의 커튼·삼각형·페이드 모션, 동작 감소 설정 대응 |
| `style.css`, `pages.css` | 홈과 상세 페이지의 디자인·반응형 배치 |
| `scene.js` | 배경 셰이더, 3D 재질과 모션 |
| `home-motion.js`, `home-motion.css` | 작품 곡선 이동·드래그·스냅, 문장과 연락처 전환, 홈 반응형 구성 |
| `detail-updates.css` | 관련 프로젝트 탐색과 활동 타임라인 |
| `media.js` | 공식 뉴스 사진·기관 로고와 원본 출처 |

`data.js`의 항목은 `id`, `type`, `title`, `summary`, `year`, `category`, `tags`, `details`, `images`, `links`, `videos`로 구성됩니다. `images`에는 `src`, `thumb`, `alt`, `role`을 넣고, 별도 출처는 `source: {label, url}`로 표시합니다. 이미지 없는 프로젝트는 타이포그래피 표지를 표시합니다. `illustrative: true` 이미지는 실제 현장 사진과 구분되도록 `CONCEPT VISUAL`을 표시합니다. 기사는 `content.js`의 `press`에서 관리합니다.

내용이나 기본 HTML을 수정한 뒤에는 다음 명령을 실행합니다.

```sh
npm run check
```

정적 경로를 다시 만들고 자료, 내부 링크, 자산, 필터, 영상 URL, HTML escaping을 검사합니다. `npm run build`는 정적 경로 생성만 수행합니다. 생성된 `works/`, `records/`, `about/`, `news/`, `motion/` 폴더의 HTML은 직접 편집하지 않습니다.

## 배치

이 폴더의 HTML·JS·CSS·`assets`·`vendor` 및 생성된 경로 폴더를 정적 호스팅에 그대로 배치할 수 있습니다. 하위 경로에서도 상대 경로로 동작합니다. 저장소의 `public/cinematic/`에 배치되며, 기본 브랜치에 푸시하면 GitHub Actions가 빌드·검사 후 [GitHub Pages](https://yhkwon2004.github.io/portfoli/)로 배포합니다.
