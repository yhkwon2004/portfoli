# 권용현 · HOURGLASS

모래시계 컨셉의 모션그래픽 포트폴리오. **한 화면에서 영화처럼** 재생되는 구조로,
페이지는 스크롤되지 않고 장(chapter)만 전환됩니다.

12장 · 84건의 기록 · 실제 입자 시뮬레이션으로 그려지는 모래시계.

```bash
npm install
npm run dev          # http://localhost:3000
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 정적 export → `out/` |
| `npm run verify` | typecheck → lint → build → 콘텐츠 감사 |
| `npm test` | 빌드 후 Playwright 33개 테스트 |
| `npm run audit` | 콘텐츠 감사 (번역 누락 · 미검토 문구 · 수치 재검증) |
| `npm run og` | OG 카드 재생성 (`public/og.png`) |
| `npm run images` | 이미지 티어 재생성 — 아래 *이미지 파이프라인* 참고 |

## 이 저장소의 유래

원본은 [yhkwon2004/portfolio-hourglass](https://github.com/yhkwon2004/portfolio-hourglass) —
의존성 0개의 단일 `index.html`(1,585줄, CSS·JS 인라인)이었습니다. 콘텐츠 데이터의 더 앞선
출처는 [yhkwon2004/-My-Portfolio_web](https://github.com/yhkwon2004/-My-Portfolio_web) 입니다.

**연출은 그대로 옮겼습니다.** 모래 시뮬레이션, 장면 전환, 상장이 선반에 떨어지는 모션, 각인
명판, 포커스 패널의 쇼릴 — 전부 원본의 타이밍과 수치를 보존했습니다. 바뀐 것은 그 연출을
지탱하는 구조입니다.

### 왜 옮겼나

원본 단일 파일의 한계는 취향 문제가 아니라 기능 문제였습니다.

| 원본 | 지금 |
|---|---|
| 스크립트가 DOM을 만들어서 **크롤러에는 빈 문서** | 12장 전체가 정적 HTML에 (148 KB) · JSON-LD 포함 |
| 한·영 문자열을 **둘 다 DOM에 넣고 CSS로 숨김** | 한 언어만 렌더 · 미번역 필드는 `lang="ko"`로 표시 |
| **링크로 특정 장면·기록을 가리킬 수 없음** | `/#projects/project-autonomous` 로 바로 열림 |
| 원본 이미지 **131 MB** 그대로 서빙 | 2티어 사전 렌더 **16 MB** (−88%) |
| 타입 없음 · 84건 데이터가 `window` 전역 | `strict` TypeScript · `satisfies Portfolio`로 빌드 시 검증 |
| 배경 탭에서도 캔버스 2개 **영구 구동** | 문서가 숨으면 루프 정지 |
| dossier에서 **Tab이 뒤쪽 타일로 새어나감** | 실제 focus trap · 포커스 복원 |
| 벽 타일 35개를 **Tab으로만** 이동 | 방향키 그리드 이동 (열 수는 실측) |
| 장면 전환을 스크린리더가 **알 수 없음** | `aria-live` 로 장 번호·이름 안내 |

## 모래시계 = 실제 시뮬레이션

CSS 애니메이션이 아니라 매 프레임 계산되는 입자 시뮬레이션입니다 (`src/lib/sim/hourglass.ts`).
SVG는 유리 용기(외곽선·마개·반사)만 그립니다.

- 알갱이가 목에서 방출 → 중력 낙하 → 기울어진 벽에 튕김 → 바닥 더미에 착지
- 더미는 84칸 heightmap. 착지할 때마다 해당 칸이 높아지고, **안식각**(angle of repose)을
  넘으면 옆으로 흘러내려 자연스러운 원뿔이 만들어집니다
- 더미 전체 부피가 현재 장으로 수렴 → 모래 높이가 곧 진행도
- 위쪽 덩어리 표면에는 깔때기 홈이 파이고, 진행될수록 깊어집니다
- 목 부분 블룸 + 알갱이를 `lighter` 합성의 모션 스트릭으로 그려 시네마틱 잔상
- 장이 바뀌면 유량이 급증했다가 다시 잔잔한 낙하로 복귀
- 0장·마지막 장에서는 주인공 크기, 나머지는 우측 상단 계기판으로 축소

> **이번에 고친 것:** 원본은 위치를 *프레임당*, 중력을 *초당*으로 적분해서 120 Hz 화면에서
> 모래가 두 배 빠르게 떨어졌습니다. 전부 초당 단위로 환산해 60 Hz에서의 모습을 그대로
> 유지하면서 프레임률과 무관하게 만들었습니다.

배경 모래도 같은 원리입니다. `z`(깊이) 하나가 크기·밝기·낙하 속도를 함께 정하므로 굵은
알갱이가 잔 알갱이를 눈에 띄게 앞지릅니다 — 원칙 장면이 말하는 규칙과 같습니다. 점이 아니라
**직전 위치에서 현재 위치까지의 선**으로 그려서, 이 모션 블러가 낙하로 읽히게 합니다.

## 장면 구성 (12장)

| # | 장 | 내용 |
|---|---|---|
| 01 | 표제 | 이름 · 헤드라인 |
| 02 | 인물 | 소개 · 태그 · 수치 요약 · **대표 성과 6건** |
| 03 | 원칙 | 모래알 우선순위 — 시급성 × 중요도 4분면 |
| 04 | 연대기 | 학력 3건 + 경력 5건 타임라인 |
| 05 | 역량 | 5개 도메인 · 81개 스킬, 근거 건수 포함 |
| 06 | **지표** | **연도별 산출 · 수상 등급 분포 · 역량 증명 깊이 — 이번에 추가** |
| 07 | 수상 | 포커스 패널 + 상장 책장 35건 (7×5) |
| 08 | 작업 | 포커스 패널 + 프로젝트 35건 (7×5, ★ 대표작 우선) |
| 09 | 자격 | 자격증 5건 |
| 10 | 분석 | SWOT 4사분면 |
| 11 | 지향 | 일하는 기준 3가지 + 지원 목표 |
| 12 | 엔딩 | 인용구 · 링크 |

장 번호와 이름은 `CHAPTERS` 배열 순서에서 자동으로 찍힙니다. 장을 끼워 넣어도 마크업의
번호를 손으로 고칠 필요가 없습니다.

### 06 지표 — 이번에 추가한 장

나머지 장이 문장으로 주장한다면, 이 장은 숫자를 그대로 내놓습니다. 세 패널 모두 84건의
기록에서 렌더 시점에 집계하므로 **낡을 수 없습니다.**

- **연도별 산출** — 수상·프로젝트 누적 막대 (2023 13 · 2024 23 · 2025 26 · 2026 8)
- **수상 등급 분포** — 35건 전체, 등급 순 ordinal 램프
- **역량 증명 깊이** — 태그별 증명 건수 상위 10개

그리고 **불리한 숫자도 같이 싣습니다.** "태그 90개 중 69개가 단 1건" — 데이터에서 가장 약한
사실이고, 이걸 수상 건수 옆에 놓는 것이 수상 건수를 믿을 이유가 됩니다. 좋은 수치만 보여주는
지표 화면은 광고입니다.

색은 눈대중이 아니라 검증했습니다. 팔레트 · 검증 기록 · 의도적으로 통과시키지 않은 체크
하나와 그 이유는 `src/data/charts.ts` 주석에 전부 적혀 있습니다.

## 접근성

연출이 전부인 사이트라서, 접근성을 "모션 제거"로 처리하지 않았습니다.

- **`prefers-reduced-motion`** — 배경 모래 루프와 필름 그레인이 *정지*하고(숨기는 게 아니라
  루프 자체를 돌리지 않습니다), 켄번즈 줌과 포커스 패널 자동재생이 꺼집니다. 남는 것은
  사용자가 직접 요청한 장면 전환뿐이며, 0.12초로 짧아져 여전히 '컷'으로 읽힙니다.
  전용 테스트 5개가 이 경로를 따로 검증합니다.
- **키보드** — 벽의 타일 35개를 방향키로 이동(열 수는 실제 렌더 기하에서 측정하므로 7·5·4열
  어디서나 맞습니다), dossier는 실제 focus trap + 포커스 복원, 닫힌 시트는 `inert`.
- **스크린리더** — 장이 바뀌면 `aria-live`가 번호와 이름을 읽습니다. 차트에는 같은 숫자를
  담은 실제 `<table>`이 `aria-describedby`로 연결되어 있습니다.
- **언어** — 미번역 영어 필드는 한국어를 보여주되 `lang="ko"`를 붙입니다. 영어 스크린리더가
  한글을 영어 음소로 읽는 것을 막습니다.

## 이미지 파이프라인

원본(마스터)은 131 MB의 카메라 JPEG과 PNG 스크린샷입니다. 아카이브로는 맞지만 웹 페이로드로는
불가능한 크기라, 디자인이 실제로 쓰는 **두 가지 크기만** 미리 렌더합니다.

| 티어 | 크기 | 쓰이는 곳 | 용량 |
|---|---|---|---|
| `thumb` | 560px | 벽 타일 · 대표 성과 · 포커스 패널 · 갤러리 | 2.3 MB |
| `full` | 1600px | dossier 히어로 | 12 MB |

```bash
node scripts/images.mjs <마스터-디렉터리> --out public/assets
```

마스터는 이 저장소에 없습니다 — `portfolio-hourglass` 저장소가 원본 보관소입니다.
`src/lib/assets.ts`의 `TIER`와 `scripts/images.mjs`의 `TIERS`는 항상 같이 고쳐야 합니다.

## 배포

정적 export이므로 서버가 없습니다. `out/`을 어디에 올려도 동작합니다.

- **GitHub Pages** — `.github/workflows/deploy.yml`이 `main` 푸시에 자동 배포합니다.
  프로젝트 사이트는 `/<repo>` 하위에서 서빙되므로 워크플로가 `NEXT_PUBLIC_BASE_PATH`를
  넘겨줍니다. Settings → Pages → Source를 **GitHub Actions**로 바꿔두세요.
- **Vercel / 버킷** — 환경변수 없이 그대로. 루트에서 서빙됩니다.

`NEXT_PUBLIC_SITE_URL`은 canonical·OG·JSON-LD의 절대 URL에 쓰입니다.

## ⚠️ 공개 전 확인

`npm run audit` 이 아래를 매번 보고합니다.

1. **분석(SWOT) 장면의 문구는 제가 데이터에서 도출한 초안입니다.** 채용 담당자가 읽는 자기
   분석이므로 본인 확인 없이 공개하면 안 됩니다. 특히 **위협(T)** 칸은 시장에 대한 주장이라
   데이터에 근거가 없습니다 — 여기부터 보세요. 다 읽고 나면
   `src/data/swot.ts`의 `SWOT_REVIEWED`를 `true`로 바꾸면 경고가 사라집니다.

   > 물려받은 초안에서 **수치 두 개가 데이터와 어긋나 바로잡았습니다**: 장려상이 7로 적혀
   > 있었지만 실제로는 6이고, "2023년 7건 → 2025년 18건"이라는 작업량 주장은 어떤 방식으로
   > 세어도 나오지 않는 숫자였습니다(실제 13 → 26). 기록이 늘면서 문장만 낡은 것이고,
   > 지표 장면이 수치를 *집계*하는 이유이자 감사 스크립트가 매번 재검증하는 이유입니다.

2. **영어 번역이 66개 필드 비어 있습니다** — 전부 프로젝트 35건의 제목·요약입니다
   (수상·학력·경력·자격은 번역 완료). 영어 화면에서 해당 항목은 한국어가 `lang="ko"`로
   표시됩니다. 진짜 해결은 사람이 번역하는 것입니다.

3. **지원 목표는 현대자동차 로보틱스랩으로 설정되어 있습니다.** 실제 공고의 조직 구성이나
   채용 요건은 확인하지 않았습니다. 바뀌면 `src/data/aim.ts`의 `TARGET`과 `swot.ts`의
   O·T 칸을 함께 고쳐야 합니다.

## 콘텐츠 수정

`src/data/portfolio.ts`의 `items[]`를 직접 고칩니다. `satisfies Portfolio` 덕분에 오타는
`npm run typecheck`에서 잡힙니다.

```ts
{ id, type, t:{ko,en}, s:{ko,en}, year, tags:[], featured, rank,
  imgs:[{u,a,r}], details:{…}, links:[{label,url}] }
```

`type`은 `profile · education · experience · certification · award · project`.
`imgs[].u`는 마스터 경로(`/assets/…`)이며 `src/lib/assets.ts`가 티어 URL로 바꿉니다.

벽 타일 수를 바꾸면 `src/styles/walls.css`의 `.wall` 열 수도 같이 맞춰 주세요. 마지막 줄이
비지 않으려면 칸 수가 열 수로 나누어떨어져야 합니다 (현재 35 = 7열 × 5행).

## 알려진 제약

- 원본 repo의 관리자 CMS(`/admin`, NextAuth, Upstash, Vercel Blob)는 옮기지 않았습니다.
  콘텐츠 수정은 `src/data/portfolio.ts` 직접 편집입니다.
- 수상 35건을 한 화면에 담기 때문에 모바일에서 타일이 작습니다. 상세는 탭하면 열립니다.
- 지표 장면은 모바일에서만 세로로 스크롤됩니다. 세 차트를 한 화면에 욱여넣어 행을 잘라내는
  것보다 낫다고 판단했습니다.
